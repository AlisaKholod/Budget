# Бюджет

Семейное приложение (PWA): бюджет (Израиль ₪ / Россия ₽), покупки с планом и фактом, вишлисты (Я / Муж / Даня), путешествия.
Данные хранятся в Google Таблице «Расходы», приложение работает с ней через Google Apps Script.

## Запуск
- Без сборки: статический сайт. Локально: `python3 -m http.server 8765`, затем http://localhost:8765
- Публикация: подключить репозиторий в Vercel (Framework Preset: Other, без команды сборки, Output Directory пустой).
- Без подключения к таблице приложение показывает демо-данные.

## Подключение таблицы
См. [apps-script/README.md](apps-script/README.md). Ключ доступа не хранить в репозитории.

## Структура
- `js/logic.js` — расчёты (без интерфейса), `tests/` — тесты (`npm test`)
- `js/store.js` — данные и связь с таблицей, `js/app.js` — интерфейс
- `apps-script/Code.gs` — мост к таблице
